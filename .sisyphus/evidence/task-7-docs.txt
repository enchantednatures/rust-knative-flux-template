--- semantics note (tag vs ref) documented:
572:> **Deploy semantics: a tag does NOT pin the deployed ref.** Flux tracks the default branch (`deploy/flux/git-repository.yaml` sets `ref.branch` to the default branch). A `v*` tag push triggers the workflow, but what gets deployed is the current default-branch ref plus whatever image tag the ImagePolicy has selected. Tags decide *when* to deploy, not *which ref* to deploy.
